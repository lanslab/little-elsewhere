安装说明

↓
1. 下载安装

点击 Pupu 卡片，获取最新 Windows 安装包并安装到电脑。若 Windows 提示“未知发布者”，请确认安装包来自本页官方 GitHub Release 后继续安装。

⚙
2. 启动使用

打开程序，Pupu 会出现在桌面。右键托盘图标可切换状态和调整大小。

↻
3. 更新说明

有新版本时可直接更新，原来的设置和桌面位置会继续保留。
